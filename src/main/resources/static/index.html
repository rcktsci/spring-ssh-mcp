Способ входа

API никогда не возвращает секреты, поэтому поля пароля, ключа и passphrase пустые — оставьте их пустыми, чтобы не менять сохранённые значения.

Нужен ровно один секрет: пароль или ключ. Переход «ключ + passphrase» → «ключ» возможен только в два шага: сохраните сервер с паролем, затем верните ключ без passphrase. Либо удалите сервер и создайте заново.

Создать токен

Через REST можно создать токен с is_token_admin и удалить последнего админ-токена — в отличие от MCP-инструментов.
